# WorkOrderIQ

WorkOrderIQ is an AI-powered facilities work order assistant designed to help summarize ticket descriptions, predict issue categories, suggest priority levels, and generate technician troubleshooting checklists.

## Project Goal

The goal of this project is to learn and demonstrate full-stack software development using modern tools such as React, TypeScript, Node.js, Express, REST APIs, PostgreSQL, GitHub, CI/CD, Docker, and AI API integration.

## Planned Tech Stack

- Frontend: React, TypeScript, Vite, Tailwind CSS
- Backend: Node.js, Express, TypeScript
- Database: PostgreSQL
- AI: OpenAI API or Gemini API
- DevOps: Docker, GitHub Actions
- Version Control: Git and GitHub

## Planned Features

- Paste a facilities work order description
- Generate a clean summary
- Predict issue category
- Suggest priority level
- Generate possible causes
- Generate technician troubleshooting checklist
- Generate suggested technician note
- Save analyzed work orders
- View ticket history
- Analyze recurring issues from exported ticket data
